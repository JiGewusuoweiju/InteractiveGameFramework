# 后台功能与最小闭环（M6，首款游戏上线后）

首版工作流：创建游戏 → 上传视频 → 添加 video/ending 节点 → 编辑选择并连线 → 定义变量与条件 → 设置起点 → 保存草稿 → 校验 → 预览 → 发布。

| 模块 | 首版要求 | 验收 |
| --- | --- | --- |
| 游戏管理 | 创建、列表、编辑名称/主题/起点 | 两个游戏的数据隔离 |
| 素材库 | 上传视频、状态、预览、引用位置 | 上传失败可重试；被发布版本引用的资源不可覆盖 |
| 流程编辑器 | 拖节点、连线、属性面板、删除确认 | 删除目标节点后能报告悬空引用 |
| 变量条件 | 声明标量、eq/neq、赋值 | 类型不匹配时禁止保存为可发布配置 |
| 预览 | 使用与 Runtime 相同规则 | 同一配置的分支结果一致 |
| 发布 | 草稿 revision 校验、生成版本、查看历史 | 旧版不被改写，玩家读取正式版 |

图片/音频、角色/道具、复制游戏、统计、玩家存档查询与多主题属于后续扩展，不在 v1 Schema 中伪造已支持字段。新增能力时按计划变更流程扩展契约。
