# 素材与发布

以下是后续 Server/Admin 自动化流程，不是首款游戏已实现的能力。首款游戏可人工维护配置与素材索引，但必须经过 Shared 校验、保留版本与素材来源记录，并在发布前验证回退；具体分发方案由 M2 真机结果决定。

上传：管理员申请上传 → 服务端验证归属/大小/类型 → 签名直传对象存储 → 服务端检查真实文件、校验和与媒体信息 → 处理完成后标记 ready。客户端上传成功不等于素材可发布。

发布：锁定草稿 revision → Schema/引用/素材就绪校验 → 创建不可变快照 → 事务更新游戏当前版本。重复请求使用幂等键避免重复版本。失败不得改变当前正式版本。

素材替换产生新资源 ID 或不可变对象版本。引用旧版本的素材不得删除或原地覆盖。回滚只调整当前版本指针；旧存档继续读取原 releaseVersion，迁移必须显式设计。

CDN、鉴权地址策略、转码参数、缓存与预加载预算在真机验证后决定。不要把所有分支视频打进小游戏首包，也不要先固定未经测试的码率和内存预算。
